# 현재 네이티브 앱

기준은 공개 v4.1.3-beta.2 이후 개선을 모은 **4.1.4-beta.1 / 421**입니다. 버전은 [build.gradle](../android/app/build.gradle)을 따릅니다.

## 구조

- 필기·선택·제스처는 Kotlin View/Canvas와 지원 환경의 전면 버퍼를 사용합니다. 라이브러리·설정 등 일반 화면은 Compose로 구성합니다.
- Room 기반 SQLite 스키마 2에 문서·페이지·객체·설정 및 OCR 결과·교정·캐시를 저장합니다. 대형 원본 자산은 파일로 보관합니다.
- PDF 원본·타일 렌더링과 고정 PDFium 기반 원문 추출을 사용합니다. PDFium 라이선스 고지는 생성 자산에 포함합니다.
- OCR은 ML Kit 디지털 잉크·한글/라틴 이미지 모델을 사용합니다. 입력 계약은 android/ocr-contracts/에 있습니다. 자동 색인은 필기·탐색 중 작업 경합과 오래된 결과 적용을 제어합니다.
- WebView는 기존 IndexedDB 이전에만 사용합니다. 배포 자산은 src/nativeAssets/와 생성된 PDFium 고지이며 legacy/web/ 편집기를 배포하지 않습니다.

## 기능과 파일

필압·기울기·historical samples, S Pen 버튼 지우개, 손가락 팬·핀치, 여러 펜·형광펜, 획/정밀/낙서 지우개, 올가미 편집, 실행 취소·다시 실행을 지원합니다. 텍스트·이미지·도형·스티키·테이프·페이지·목차·폴더·검색·녹음과 공유 기능을 포함합니다.

텍스트는 도구를 선택하고 페이지를 탭해 그 위치에서 입력합니다. 손가락 필기 차단과 별개로 추가할 수 있으며, 페이지 로딩 중 요청을 보존합니다. 상자 선택·재편집·이동·너비 조절·확대/축소·회전, 한글 조합, 부분 서식과 저장을 연결합니다. 플로팅 도구막대는 선택·입력 상태에 맞는 작업을 표시하고 팝오버는 키보드와 화면 경계에 맞춰 배치합니다. 정밀 지우개는 텍스트·도형·형광펜의 원 내부만 제거합니다. [텍스트 UI와 검증](TEXT-UI-LOCAL.6-KO.md), [정밀 지우개](TEXT-ERASER-LOCAL.5-KO.md)를 참고하십시오.

문서 검색과 현재 페이지 손글씨 OCR은 좁은 화면에서도 상단 직접 버튼으로 접근합니다. 검색은 PDF 원문의 문자 좌표, OCR 단어/영역, 텍스트·수식 객체의 위치를 강조합니다. 좌표 없는 옛 결과나 전체 교정에는 단어 위치를 추측하지 않습니다. OCR 결과는 단일 편집란과 전체 복사·교정 저장·텍스트 삽입으로 제공하며 내부 진단과 영역별 후보 목록은 표시하지 않습니다.

기본 .ifnote는 페이지 JSON·원본 자산을 스트리밍하는 ZIP v5입니다. 3.x JSON 가져오기와 명시적인 호환 JSON 내보내기를 지원합니다. PDF/PNG/XFDF 내보내기와 FileProvider 공유를 사용합니다. 저장·이전·파일 검증에서는 원본 필기·자산·알 수 없는 메타데이터를 보존해야 합니다.

## 현재 개선과 검증

[4.1.4 Beta 1](RELEASE-4.1.4-BETA.1-KO.md), [OCR](OCR-NATIVE-IMPLEMENTATION-KO.md), [펜·올가미](PEN-4.1.3-PERFORMANCE-KO.md)에 동작과 기존 실행 증거를 구분해 기록합니다. 과거 에뮬레이터 수치를 물리 S Pen 지연이나 일반 필기 정확도로 해석하지 않습니다.

빌드·JVM 검사는 [Android 빌드 안내](../android/README-BUILD-KO.md)를 따릅니다. 실제 기기 계측은 명시한 별도 .debug 앱에서 실행합니다.
