# BADNOTE 4.2.2 통합판

앱 버전 4.2.2, 빌드 433

## 이번 통합판

- Goodnotes 문서(`.goodnotes`)와 백업(`.goodnotes.zip`)을 바로 가져옵니다. 지원하는 필기·텍스트·이미지·도형은 편집 가능한 객체로 가져오고, 페이지 순서와 PDF 배경 및 백업의 하위 폴더를 보존합니다. PDF 스티커는 이미지로 변환하며 가림 테이프나 녹음 등 빠진 요소의 개수를 표시합니다.
- 카드 날짜와 수정순 정렬에 같은 편집 시각을 사용합니다. 기존 생성일과 수정일은 보존하며, 실제 편집을 저장한 시각은 별도로 기록합니다. 새 수정일은 백업과 `.ifnote` 복원에도 유지됩니다.
- 라이브러리 목록과 썸네일에 필요한 데이터를 묶어 읽고, 검색어에 맞는 OCR 결과를 배치로 조회합니다. 검색 중 노트를 열면 진행 중인 검색을 취소합니다.
- 설정의 아이콘과 항목 간격을 다듬고 화면 전환 속도를 부드럽게 조정했습니다. 언어 선택 표기와 변경 안내 문구를 간결하게 정리했습니다.

## 4.2.2에 포함된 기능

- 펜으로 그린 뒤 잠시 멈춰 직선·곡선·원·타원·사각형으로 변환할 수 있습니다. 문질러 지우기와 한 번에 실행 취소하는 동작도 개선했습니다.
- 연필의 흑연 질감이 필압과 펜 기울기에 반응합니다. 새로 입력된 구간을 계산하고 이전 구간을 재사용해 입력 중 렌더링 작업을 줄였습니다.
- 도구막대에서 펜과 연필을 전환하고, 펜·연필·형광펜의 색과 굵기를 각각 기억합니다. 색상 팔레트에서 자주 쓰는 색을 관리할 수 있습니다.
- 여러 문서 창에서 서로 다른 펜 설정을 바꿔도 각각 저장됩니다. 키보드의 펜 단축키로 연필에서 일반 펜으로 전환할 수 있습니다.
- PDF·이미지·BADNOTE·Xournal 파일을 가져올 수 있습니다. Xournal 내보내기는 일반 필기 획을 편집 가능한 상태로 유지하며, 효과의 보존이 필요한 페이지에는 이미지를 사용합니다. Samsung Notes와 Notability의 문서는 원본 앱에서 PDF로 내보낸 후 가져올 수 있습니다.

## 설치

- `bad-note-Android-4.2.2-Update.apk`는 기존 업데이트용 앱(`com.inkforge.note4`)에 설치합니다.
- `bad-note-Android-4.2.2-SideBySide.apk`는 병행 설치용 앱(`com.inkforge.note5`)에 설치합니다.

4.2.2 최초판을 사용 중이면 이 페이지에서 같은 설치 유형의 APK를 선택해 통합판으로 업데이트할 수 있습니다. Android 6.0(API 23) 이상을 지원합니다.
