# BADNOTE 4.2.2

- 펜으로 그린 뒤 잠시 멈춰 직선·곡선·원·타원·사각형으로 변환할 수 있습니다. 문질러 지우기와 한 번에 실행 취소하는 동작도 개선했습니다.
- 연필의 흑연 질감이 필압과 펜 기울기에 반응합니다. 새로 입력된 구간을 계산하고 이전 구간을 재사용해 입력 중 렌더링 작업을 줄였습니다.
- 도구막대에서 펜과 연필을 전환하고, 펜·연필·형광펜의 색과 굵기를 각각 기억합니다. 색상 팔레트에서 자주 쓰는 색을 관리할 수 있습니다.
- 여러 문서 창에서 서로 다른 펜 설정을 바꿔도 각각 저장됩니다. 키보드의 펜 단축키로 연필에서 일반 펜으로 전환할 수 있습니다.
- PDF·이미지·BADNOTE·Xournal 파일을 가져올 수 있습니다. Xournal 내보내기는 일반 필기 획을 편집 가능한 상태로 유지하며, 효과의 보존이 필요한 페이지에는 이미지를 사용합니다. Goodnotes, Samsung Notes, Notability의 문서는 원본 앱에서 PDF로 내보낸 후 가져옵니다.

## 설치

- `bad-note-Android-4.2.2-Update.apk`는 기존 업데이트용 앱(`com.inkforge.note4`)에 설치합니다.
- `bad-note-Android-4.2.2-SideBySide.apk`는 병행 설치용 앱(`com.inkforge.note5`)에 설치합니다.

Android 6.0(API 23) 이상을 지원합니다.
