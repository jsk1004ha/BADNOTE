# bad note 3.3.30

## S Pen 버튼 지우개

- Android MotionEvent의 접촉 시작·이동·종료를 편집기 입력에 직접 연결합니다. WebView가 버튼을 누르는 동안 PointerEvent를 보내지 않거나 취소하더라도 실제 필기가 지워집니다.
- 네이티브 입력과 WebView 입력이 중복 처리되지 않도록 하며, 버튼을 놓으면 같은 접촉에서 이전 필기 도구로 돌아갑니다.
- 호버 중에는 필기를 지우지 않습니다. 읽기 모드에서도 원본을 보존합니다.
- 지우개 판정에 필기 점 사이의 선분을 포함합니다. 점 간격이 넓은 획도 지워지며, 정밀 지우개는 선분과 지우개 경계의 교차점을 계산해 닿은 부분만 잘라냅니다.

## 파일 내보내기

- 노트 화면 **더 보기(⋮) → 파일 내보내기**, 또는 라이브러리의 **문서 메뉴 → 파일 내보내기**에서 형식을 선택합니다.
- **노트 파일 (.ifnote)**: 모든 페이지, 편집 가능한 객체, 삽입 이미지, PDF 배경, 녹음을 담습니다. 다른 기기에서도 배경이 복원되도록 내부 저장소의 이미지 데이터를 파일 안에 포함합니다. 기존 가져오기 기능과 호환됩니다.
- **PDF 파일 (.pdf)**: 모든 페이지를 배경·필기·텍스트·이미지와 함께 저장합니다. 편집기 용지 비율을 유지하며 페이지별로 래스터화합니다. PDF에서 텍스트 선택·검색과 개별 획 편집은 지원하지 않으므로 편집용 백업에는 `.ifnote`를 사용합니다.
- Android의 저장 위치 선택 창을 사용합니다. 파일은 앱의 내부 폴더 바깥에 저장되며 앱 삭제 후에도 남습니다. 기존 파일을 덮어쓰지 않고 새 문서로 생성합니다.
- 파일 데이터는 작은 청크로 임시 파일에 기록한 뒤 선택한 위치에 복사합니다. 실제 쓰기 완료 후 성공을 표시하고, 취소와 저장 실패를 구분합니다.

## 확인

- 브라우저 입력 회귀 테스트: 기존 낙서 지우기·확대 유지·S Pen 버튼 입력과 네이티브 접촉 전용 경로.
- 파일 테스트: 별도 저장소에서 노트 재가져오기, PDF 페이지 수·비율·배경 검증 및 렌더링 확인, 네이티브 청크 전송·취소·오류 처리.
- Android 테스트 앱의 실제 MotionEvent 전달과 시스템 저장 창 확인. 실제 S Pen 하드웨어의 버튼 조작은 사용자 확인이 필요합니다.

## 설치

로컬 3.3.29와 같은 서명키로 빌드합니다. 같은 패키지의 로컬 3.3.29 위에는 앱을 삭제하지 않고 업데이트 설치합니다. `SideBySide` APK의 패키지는 `com.inkforge.note5`, `Update` APK는 `com.inkforge.note4`입니다. 파일명의 SideBySide가 항상 새 앱 설치를 뜻하는 것은 아닙니다.
