# BADNOTE 4.1.3 Beta 2

## 로컬 수정판 `4.1.3-beta.2-local.4`

공개 태그 `v4.1.3-beta.2` (`d6873da66a2fd76029bf89141d3af81606e9480f`)를 기준으로 수정했다. versionCode는 418이며 GitHub 릴리스·태그를 변경하거나 커밋·푸시하지 않는다. 원래 공개 배포 내용은 별도 보관 기록으로 옮겼다.

- **local.4 후속 수정**: 페이지 위 텍스트 입력, 한글 조합·상자 편집·7개로 묶은 서식 메뉴, 텍스트·형광펜·도형 지우개와 손 도구의 − 아이콘을 적용했다. [텍스트 입력과 검증](TEXT-LOCAL.4-KO.md).
- **local.4 페이지 관리**: 페이지 관리 패널을 한 열의 작은 미리보기로 축소했다. 상단 기본 도구 모음은 유지하고 펜 팔레트를 남은 필기 영역에 맞춘다. 페이지 선택을 중앙 정렬하며, 버튼 옆 플로팅 메뉴에서 대상 페이지의 앞·뒤에 빈 페이지를 추가하거나 해당 페이지만 삭제한다. [변경과 검증](PAGES-LOCAL.4-KO.md).
- **local.3 수정**: Android가 회수한 페이지·획 표시 캐시의 재기록을 추가했다. 원본 획과 경로 캐시는 유지한다. 캐시 예산을 넘긴 표시 복구 검사는 통과했으나 고밀도 지우기의 표시 지연은 남아 있다. [변경과 검증](INK-LOCAL.3-KO.md).
- **local.2 수정**: 상단 도구의 840dp 강제 두 행 조건 제거, 확대·지우기·도구 전환 중 필기 화면 유지, 페이지 드래그의 주변 썸네일 이동 애니메이션. [변경과 집중 검증](EDITOR-LOCAL.2-KO.md).
- **S Pen**: 접촉 중 측면 버튼을 놓아도 펜을 화면에서 뗄 때까지 지우개를 유지한다. 이동·과거 표본에도 적용하며 다음 접촉은 현재 도구로 돌아간다. 버튼을 계속 누른 채 다시 접촉하면 지우개를 유지한다. 접촉 취소·도구 변경과 무관한 마우스 이벤트를 구분한다.
- **손글씨 OCR**: 한글·영어의 실제 모델 후보, 줄 단위 입력 정규화, 한영 혼합 검토를 개선했다. 올가미 선택 필기를 따로 변환하며 결과를 검토·교정한 뒤 삽입한다. 원본 획은 삭제하지 않는다.
- **수식 OCR**: 별도 수식 변환에서 숫자·기본 연산·괄호·분수·지수와 여러 줄의 제한된 손글씨 수식을 처리한다. 범용 수학 OCR이나 이미지 수식 전체를 지원한다고 표시하지 않는다.
- **올가미와 렌더링**: MOVE마다 선택 획 전체를 JSON 복사·변환하던 경로를 제거했다. 드래그 중에는 표시 위치만 이동하고 UP에서 한 번 확정한다. 취소·한 번의 실행 취소/다시 실행, 겹침 순서·잠긴 객체·숨긴 객체·원시 필기 메타데이터를 보존한다.
- **다획 필기·지우개**: 긴 획의 불변 표본·안정된 브러시 경로를 재사용하고, 새 획은 기존 화면 위에 합성하여 주변의 모든 획을 다시 그리지 않는다. 지우개는 한 입력의 경로를 모아 정확한 충돌·분절을 계산하며 반복 JSON 복사를 없앴다. API 29 이상에서는 변경된 현재 장면을 보관된 하드웨어 그리기 명령으로 바로 표시하고, 정확한 비트맵 캐시는 접촉이 끝난 뒤 별도 작업자에서 만든다. 이전 세대의 작업은 화면에 반영하지 않는다. 저장 JSON 생성과 실행 취소 크기 계산도 입력 스레드에서 분리했다. 원시 표본·브러시 모양·겹침·취소·실행 취소와 영속 capture 순번은 유지한다.
- **다페이지 문서**: 페이지 목록은 재사용되는 썸네일 셀로 표시한다. 선택한 페이지의 읽기·준비를 우선 처리하고 썸네일 그리기를 저장 큐와 분리하여, 페이지 수만큼 전체 필기 데이터를 함께 올리지 않는다. 메타데이터·쪽 수는 묶어서 조회한다.
- **PDF 확대**: 기존 해상도 타일과 제한된 크기의 전체 페이지 미리보기를 유지한 채 목표 해상도 타일로 교체한다. 확대·이동 간 유효 요청을 공유한다.
- **검색·OCR UI**: 검색과 현재 페이지 OCR을 문서 옵션 밖으로 이동했다. 검색 결과의 좌표가 있는 일치 영역을 강조하고, OCR은 진단·영역 카드 없이 한 편집란에 출력한다. 전체 교정·복사·단일 객체 삽입을 지원한다.
- **큰 수식**: 구조 분석에는 원본을 사용하고 모델 입력만 제한된 오차로 단순화한다. 안전하게 나눌 수 있는 큰 입력은 분할하며, 실패한 줄과 정상 결과를 구분한다. 범용 수학 인식이나 무제한 입력을 의미하지 않는다.
- **페이지 관리·삭제**: 우측 상단의 페이지 아이콘을 다른 도구와 같은 48dp 크기로 배치했다. 하단의 고정 `페이지 메뉴` 패널과 앞/뒤 이동 항목을 없앴다. 썸네일을 길게 누르고 원하는 위치로 끌어 순서를 바꾸며, 삽입 위치 표시와 가장자리 자동 스크롤을 제공한다. 쪽 추가는 목록 상단의 아이콘, 복제·북마크·삭제는 각 쪽의 점 세 개 메뉴에서 실행한다. 삭제는 추가 확인창 없이 해당 페이지에 적용하며, 마지막 한 쪽 보호와 저장 완료 대기를 유지한다. 다른 페이지를 삭제하거나 순서를 바꿔도 현재 페이지의 필기와 실행 취소 상태를 보존한다.

Goodnotes의 [S Pen 버튼 지우개 안내](https://support.goodnotes.com/hc/en-us/articles/8373153754639-Using-the-Eraser-with-the-Samsung-S-Pen-Button-on-Android)는 버튼을 놓으면 원래 도구로 복귀한다고 설명한다. 이번 동일 접촉 유지 동작은 그 안내를 그대로 복제한 것이 아니라 요청한 동작이다. [선택 필기 텍스트 변환](https://support.goodnotes.com/hc/en-us/articles/7353695997199-Convert-handwriting-to-text)과 [별도 수식 변환](https://support.goodnotes.com/hc/en-us/articles/7443597657231-Convert-your-Handwritten-Math-to-Rendered-Math)의 사용 흐름을 참고했다.

페이지 관리에는 Goodnotes의 [사이드바·썸네일에서 페이지 삭제](https://support.goodnotes.com/hc/en-us/articles/7353718669327-Deleting-pages-and-covers)와 [썸네일 길게 누르기·드래그 순서 변경](https://support.goodnotes.com/hc/en-us/articles/7353718659343-Reorder-Pages-in-a-Goodnotes-Document), Samsung Notes의 [Sort pages에서 길게 눌러 드래그하는 방식](https://insights.samsung.com/2025/03/27/10-tips-for-increased-productivity-with-samsung-notes/)을 참고했다. Goodnotes의 [부분·획 단위 지우개 안내](https://support.goodnotes.com/hc/en-us/articles/7353718249231-Erase-handwriting-and-page-content-with-the-Eraser-tool)와 Samsung Notes의 [획·영역 지우개 안내](https://www.samsung.com/us/support/answer/ANS10003634/)는 기존 도구 동작을 구분하는 참고 자료다. 다른 앱의 비공개 렌더링 구현을 추정하거나 휴지통·일괄 선택 기능까지 복제하지 않는다.

### 로컬 설치 주의

`build/apk/`의 `bad-note-Android-4.1.3-beta.2-local.4-Debug.apk`는 `com.inkforge.note4.debug`로 공개 앱과 분리된다. `Update.apk`와 `SideBySide.apk`는 로컬 인증서로 서명하므로 동일 패키지의 공개 APK 위에 설치할 수 없다. 공개 릴리스 인증서의 개인 키가 이 작업 환경에 없으며, 기존 앱 삭제나 데이터 초기화로 우회하지 않는다. 정식 업데이트에는 원래 서명 키로 다시 빌드해야 한다.

최소 API 23·대상 API 36, DB 스키마와 원본 파일 형식은 유지한다. APK는 `-PbadnoteOcrBeta=true`로 빌드한다. 실행 증거와 측정 제한은 [펜·올가미 검증](PEN-4.1.3-PERFORMANCE-KO.md), OCR 세부 사항은 [OCR 구현 기록](OCR-NATIVE-IMPLEMENTATION-KO.md)에 구분해 기록한다.

이전 배포·설계 내용은 [보관 기록](archive/4.1.3/RELEASE-4.1.3-BETA.2-KO.md)으로 옮겼습니다.
