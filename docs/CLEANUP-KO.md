# 직접 삭제할 파일

삭제 대기 파일은 준비했으며 삭제 스크립트는 실행하지 않았습니다. 최신 소스는 프로젝트 루트의 android/에 있습니다. GitHub에는 반영하지 않습니다.

## 바로 지울 수 있는 폴더

프로젝트 루트의 **_delete_after_review/** 전체를 탐색기에서 삭제해도 됩니다. 약 8.3 MiB이며 APK에 포함되지 않는 Android 웹 중복본·Tesseract 모델과 폐기 도구만 들어 있습니다. 원본은 프로젝트 밖 소스 백업에도 있습니다.

## 이전 작업 폴더까지 정리

**.worktrees/beta2-improvements/**는 약 6.5 GiB입니다. 이미 루트로 옮긴 소스와 로컬 빌드 캐시, 검증용 에뮬레이터 이미지가 들어 있습니다. 아래 스크립트는 Git 등록 상태를 확인하고, 이미 등록 해제된 이전 실행의 잔여 파일도 이어서 정리합니다.

프로젝트 루트에서 PowerShell로 목록과 검증 결과를 먼저 볼 수 있습니다. 이 명령은 삭제하지 않습니다.

    & ./tools/cleanup_local.ps1

실제 삭제를 원할 때 직접 실행하십시오.

    & ./tools/cleanup_local.ps1 -Delete

스크립트는 외부 백업 ZIP 해시, 이전 작업 폴더에 남은 소스, 키·SDK 설정 사본, APK·검증 기록 보존을 확인한 뒤 정확히 위 두 폴더만 삭제합니다. 이전 시도에서 이미 지워진 파일은 허용하지만, 변경된 소스나 백업에 없는 새 파일을 발견하면 중단합니다. 알려진 빌드 산출물·Python 캐시·검증용 에뮬레이터는 삭제 대상으로 구분합니다. 현재 앱 소스, 현재 build/의 APK·의존성, 기존 기기 백업, Git 브랜치·stash와 외부 복구 백업은 보존합니다.

Windows의 260자 제한을 넘는 경로는 확장 경로로 처리합니다. 시스템 레지스트리나 전역 Git 설정은 바꾸지 않습니다. 오류가 나면 build/cleanup/에 실행 기록을 남기며, 중간에 멈춘 뒤에도 같은 명령으로 다시 실행할 수 있습니다.

복구 자료는 [badnote-backups/2026-10-20-workspace-cleanup](../../badnote-backups/2026-10-20-workspace-cleanup)에 있습니다. GitHub 명령은 포함하지 않습니다.

## 유지하는 자료

legacy/web/는 현재 브러시·아이콘 회귀 도구가 참조하므로 삭제 대상에서 제외했습니다. docs/archive/는 버전 이력이며 현재 안내와 분리했습니다. 기존 build/device-backup-2026-10-02/도 삭제 대상이 아닙니다.

자동 승인 검토가 폴더 전체 이동·삭제와 중복 파일 삭제 명령을 정책상 차단했습니다. 요청에 따라 제가 삭제하는 대신 직접 실행할 목록과 스크립트를 준비했습니다.
