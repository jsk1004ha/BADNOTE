# 공개 4.1.3 Beta 2 배포 이력

> 과거 배포·설계 기록입니다. 현재 작업 기준은 [문서 안내](../../README.md)를 확인하십시오.

## 원래 공개 Beta 2 배포 기록

펜 입력의 중복 처리와 쓰는 획의 깜빡임을 줄이는 베타입니다. Beta 1의 OCR 경합 완화와 페이지 탐색 개선을 포함합니다.

- 한 MOVE 이벤트의 모든 과거 입력점을 보존한 뒤 화면 갱신을 한 번 요청합니다. 입력 스레드에서 전체 획을 JSON 문자열로 직렬화하고 렌더러에서 다시 파싱하던 작업을 줄였습니다.
- 쓰는 획을 화면에서 먼저 지우는 대신 별도 레이어에서 재생해 교체합니다. 브러시의 테이퍼·필압·투명도 계산을 유지합니다.
- 이전 획의 표시 전환 중 다음 획은 일반 Canvas로 표시합니다. 빠른 연속 필기와 취소 후 전면 버퍼 복귀를 보호합니다.
- 원본 입력점, 저장 형식, 실행 취소·다시 실행과 OCR 기능을 유지합니다. 런타임 의존성과 데이터베이스 스키마 변경은 없습니다.

## 설치

- `bad-note-Android-4.1.3-beta.2-Update.apk`: 기존 `com.inkforge.note4` 업데이트용.
- `bad-note-Android-4.1.3-beta.2-SideBySide.apk`: `com.inkforge.note5` 병행 설치용. 기존 병행 설치 앱은 업데이트합니다.
- 버전 `4.1.3-beta.2`, versionCode 414, 최소 Android 6.0. 이전 베타와 같은 인증서로 서명합니다.
- GitHub prerelease로 배포하며 정식 Latest `4.0.1`을 유지합니다. `-PbadnoteOcrBeta=true`로 OCR 베타 경로를 활성화합니다.

## 검증 범위

에뮬레이터에서 1,024개 입력을 처리하는 p95 중앙값은 3.35ms로 측정했습니다. 단위 테스트 63개가 통과했습니다. 원본 측정의 편차가 크므로 개선율을 실기기의 체감 성능으로 해석하지 않습니다.

두 패키지의 실제 서명 APK 업데이트와 문서·필기 보존을 확인했습니다. 업데이트 후 새 필기를 저장하고 앱을 재실행했으며, SideBySide의 이미지 첨부 샘플은 원본 바이트 보존까지 확인했습니다.

[측정·회귀 검사 기록](https://github.com/jsk1004ha/BADNOTE/blob/v4.1.3-beta.2/docs/PEN-4.1.3-PERFORMANCE-KO.md)에 동일 입력의 전후 수치와 화면 검사 결과를 기록합니다. 입력 처리 시간과 GPU·화면 주사·실물 S Pen 지연은 구분합니다. 실제 Galaxy/S Pen의 체감 지연과 모든 기기의 깜빡임 제거를 보장하는 수치는 측정하지 않았습니다.

전면 레이어 교체에는 화면 크기의 임시 렌더링 대상이 추가로 필요합니다. 반투명 브러시와 지원되지 않는 환경은 기존 Canvas 경로를 사용합니다. 전체 획 재생을 유지하므로 아주 긴 한 획의 렌더링 비용은 남습니다.
