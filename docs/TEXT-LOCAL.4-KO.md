# 페이지 위 텍스트 입력과 지우개 — local.4 후속 수정

작업 기준은 4.1.3-beta.2-local.4 / versionCode 418이다. 로컬 소스·검증·APK만 변경하며 커밋·푸시·PR·원격 배포는 하지 않는다.

## 입력과 메뉴

[Goodnotes 공식 텍스트 도구 안내](https://support.goodnotes.com/hc/en-us/articles/7353727615375-Type-text-with-the-Text-Tool)와 공식 안내의 객체 메뉴·활성 도구 메뉴 화면을 확인했다. 텍스트 도구를 고른 뒤 페이지를 탭하면 그 위치에 테두리와 입력란을 표시하고 Android 키보드를 연다. 기존 문자열 입력창은 사용하지 않는다. ‘펜으로만 필기’ 설정도 텍스트 추가 탭을 막지 않으며, 페이지 로딩 중 탭은 해당 페이지가 준비된 뒤 한 번 처리한다.

- 기존 상자는 한 번 탭해 선택하고 다시 탭해 입력한다. 바깥을 탭하거나 완료를 누르면 저장한다. 빈 새 상자와 취소한 편집은 저장하지 않는다.
- 입력 중 플로팅 메뉴는 **색상·크기·글꼴·BI·정렬·더보기·완료의 7개**다. 굵게·기울임·밑줄·취소선·텍스트 강조는 BI 메뉴, 목록·상자 스타일·도구 고정·복사/잘라내기·복제·앞/뒤·잠금·삭제·기본값 저장은 더보기에서 연다.
- 선택한 글자에는 부분 서식을 적용한다. 커서만 놓여 있으면 이후 입력할 글자에 서식을 적용한다. Android의 한글 조합 입력, 선택, 복사·붙여넣기를 사용한다.
- 상자를 드래그해 이동하고 양옆의 파란 손잡이로 너비를 조절한다. 모서리 손잡이는 글자와 상자를 함께 확대·축소하고 위쪽 손잡이는 회전한다. 줄 수에 따라 높이가 늘어나며 한글 대체 글꼴의 높이를 반영한다.
- 색상, 글꼴(기기 기본 고딕·명조·고정 폭), 크기, 줄 간격, 정렬, 배경, 테두리, 여백을 지원한다. 서식 정보는 노트 파일에 저장되고 화면·미리보기·PDF 렌더링에 함께 사용한다. Goodnotes의 전용 글꼴이나 AI 기능을 복제한 것은 아니다.
- 텍스트 도구 고정을 켜면 계속 새 상자를 만든다. 다른 도구를 고르면 고정은 풀린다. 텍스트 도구로 페이지를 길게 누르면 페이지 너비의 입력 상자를 만든다. 번호·글머리 목록은 Enter로 이어지고 빈 항목에서 Enter를 누르면 종료한다.
- 한 편집 세션은 문서 실행 취소 한 번으로 되돌린다. 페이지·문서·도구 전환, 앱 일시 중지, 화면 회전 전에 입력을 확정한다.

## 지우개와 손 도구

획 지우개와 정밀 지우개 모두 텍스트·형광펜·도형에 적용된다. 형광펜은 획 모드에서 닿은 획을 지우고 정밀 모드에서는 닿은 부분을 잘라낸다. 텍스트는 상자 단위, 도형은 실제 윤곽에 닿은 객체 단위로 지운다. 잠김·숨김 객체 보호, S Pen 버튼 지우개, 접촉 취소와 실행 취소·다시 실행을 유지한다. 손 도구의 축소 아이콘은 ×에서 −로 바꿨다.

페이지 점 세 개 메뉴의 앞·뒤 페이지 추가도 포함한다. 삭제로 페이지의 저장 순번에 빈칸이 생겨도 삽입 위치가 화면과 일치하며, 순번을 정리하는 것만으로 기존 OCR 결과를 무효화하지 않는다. 상세한 페이지 관리 변경은 [페이지 관리 기록](PAGES-LOCAL.4-KO.md)에 있다.

실제 손가락·펜 탭, 화면 키보드 표시, Android InputConnection을 통한 한글 조합, 줄바꿈과 표시 높이, 7개 메뉴와 BI 하위 메뉴, 선택 글자·이후 입력 글자의 서식 구분, 번호 목록 이어쓰기·종료, 페이지 너비 입력, 선택 후 재편집, 드래그 이동·너비 조절, 저장·재열기, 빈 상자·취소, 편집 세션 단위 실행 취소·다시 실행, 로딩 중 탭 재처리와 도구 고정을 확인했다. 지우개는 텍스트·형광펜·도형과 잠김/숨김 보호, S Pen 버튼·접촉 취소·실행 취소를 검사했다. 축소 버튼은 − 표시와 실제 배율 감소를 확인했다.

입력 중 서식 메뉴의 기기 기본 팝업이 항목 실행을 완료하기 전에 검사하던 테스트와, 키보드 애니메이션 중 이전 위치를 탭하던 테스트를 수정했다. 최종 검사는 팝업 완료와 실제 위치가 안정된 뒤 동작을 검사한다. 한글 글꼴의 줄 높이 차이로 마지막 줄이 가려지던 실제 표시 오류도 수정했다.
