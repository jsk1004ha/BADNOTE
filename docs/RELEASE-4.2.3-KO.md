# BADNOTE 4.2.3

앱 버전 4.2.3, 빌드 434

## 변경 사항

- 새 버전이 있으면 문서 목록에 업데이트 알림을 표시합니다.
- 업데이트 화면에서 현재 버전, 변경 사항, 다운로드 진행률을 확인하고 다운로드·재시도·설치를 이어갈 수 있습니다.
- 업데이트 알림과 화면 전환에 부드러운 애니메이션과 SVG 아이콘을 적용했습니다. 시스템의 애니메이션 설정을 따릅니다.
- [4.2.2 통합판](https://github.com/jsk1004ha/BADNOTE/releases/tag/v4.2.2%2B433)의 Goodnotes 가져오기, 노트 날짜 보존, 카드 수정순 정렬과 라이브러리 최적화가 포함됩니다.

## 설치

기존 4.2.2 앱에서 **설정 → 업데이트 확인**을 선택하면 4.2.3을 받을 수 있습니다.

- 업데이트용 APK는 업데이트용 앱(`com.inkforge.note4`)에 설치합니다.
- 병행 설치용 APK는 병행 설치용 앱(`com.inkforge.note5`)에 설치합니다.

Android 6.0(API 23) 이상을 지원합니다.
