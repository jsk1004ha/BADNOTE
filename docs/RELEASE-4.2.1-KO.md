# BADNOTE 4.2.1

갤럭시 탭·S Pen용 BADNOTE의 정식 Android 릴리스입니다.

## 주요 변경

- 텍스트 상자와 페이지 직접 입력, 한글 입력기, 텍스트 서식, 정밀 지우개, 펜 버튼 및 올가미 동작을 개선했습니다.
- 페이지 검색에서 PDF 원문·입력 텍스트·OCR과 교정 내용을 찾을 수 있습니다. 유니코드 대소문자와 JSON 이스케이프가 있는 텍스트도 검색하고, 새 검색이 시작되면 이전 PDF 검색을 취소합니다.
- PDF 내보내기는 지원되는 필기와 텍스트를 벡터로 유지하며 페이지 단위로 결과를 조립합니다. 가져온 원본 PDF의 배경은 래스터화합니다. XFDF는 지운 부분을 반영한 주석 모양을 보존합니다.
- 문서를 별도 창으로 열고, 키보드 단축키를 사용하고, 선택한 폴더에 변경된 노트를 자동 백업할 수 있습니다. PDF 다크 모드는 화면의 PDF 배경에 적용됩니다.
- 영구 삭제 시 파일 회수 후보를 저장합니다. 다음 앱 프로세스 시작 시 공유 자산과 복구 가능한 휴지통의 참조를 확인한 뒤 미참조 파일만 회수합니다.
- 보이는 페이지의 렌더링, 캐시 재생, 오버레이가 동일한 페이지 높이 정보를 재사용합니다.

## 설치

| 파일 | 설치 대상 |
| --- | --- |
| `bad-note-Android-4.2.1-Update.apk` | 기존 업데이트용 앱 `com.inkforge.note4` |
| `bad-note-Android-4.2.1-SideBySide.apk` | 병행 설치용 앱 `com.inkforge.note5` |

Android 6.0(API 23) 이상이 필요합니다. 다른 패키지로 노트를 옮길 때는 `.ifnote` 내보내기와 가져오기를 사용합니다.
