# 3.3.27 변경 내역

## 문질러 지우기

- 설정 언어가 영어 또는 포르투갈어이면 원형 동작 대신 좌우로 반복해서 긁는 동작을 문질러 지우기로 인식합니다.
- 좌우 방향 전환, 중심선 통과, 유효 왕복 거리, 수평 이동 우세를 함께 검사해 일반 필기체와 반복 원형 획의 오삭제를 줄였습니다.
- 초기 수평/수직 이동 비율 1.35:1은 반복 타원도 통과해 폐기했고, 실제 RED/GREEN 평가를 거쳐 3:1로 강화했습니다.
- 한국어, 일본어, 중국어는 기존 원형 및 혼합 낙서 인식을 유지합니다.
- 삭제 반경과 객체 교차 판정은 변경하지 않아 문지른 경로에 실제로 닿은 객체만 지웁니다.

## 버전

- 표시 버전과 자동 업데이트 비교 버전을 `3.3.27`로 올렸습니다.
- Android `versionCode`는 `359`입니다.
- 앱 내 업데이트 내역은 한국어, 영어, 일본어, 중국어, 포르투갈어로 제공합니다.

## 검증

- 변경 전 테스트에서 영어 반복 원형 동작이 대상 필기를 지우는 실패를 재현했습니다.
- 변경 후 영어·포르투갈어 좌우 스크래치, 영어 반복 원형 보호, 포르투갈어 필기체 진행 획 보호, 한국어 기존 원형 동작, 인접 객체 보호가 모두 통과했습니다.
- 전체 Playwright 웹 회귀 테스트가 `3.3.27` 기준으로 통과했고 콘솔 오류와 예기치 않은 대화상자가 없었습니다.
- update 및 side-by-side Android release 빌드가 성공했습니다.
