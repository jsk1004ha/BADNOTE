# bad note 3.3.29

## 입력 동작 수정

- 낙서 지우기는 같은 영역을 크게 왕복하는 동작이 4회 이상이고, 해당 펜 획을 3회 이상 지나간 경우에만 실행합니다. 표시 언어에 따라 일반 글씨를 더 쉽게 지우던 차이를 없앴습니다.
- 낙서가 한 번 스친 획, 잠긴 객체, 형광펜, 텍스트, 도형은 낙서 지우기 대상에서 제외합니다. 형광펜으로 그린 동작도 낙서 지우기를 실행하지 않습니다. 설정에서 기능을 끌 수 있습니다.
- 빠른 연속 필기로 발생한 더블클릭이 배율을 100%로 되돌리지 않습니다. 사이드바, 키보드, 창 크기가 바뀌어도 페이지의 표시 크기를 유지합니다. 도구 모음의 **페이지 맞춤**을 누르면 현재 화면 너비에 다시 맞춥니다.
- S Pen 버튼 상태를 Activity의 터치·일반 모션 경로에서 먼저 전달합니다. 8ms 이동 이벤트 제한으로 버튼 변화가 누락되지 않습니다.
- 버튼을 누르거나 뗄 때 현재 접촉도 함께 전환합니다. 펜을 화면에서 떼지 않고 **필기 → 버튼 지우개 → 필기**로 이어갈 수 있습니다. 버튼을 뗀 MOVE, 표준 KeyEvent, 보조 버튼, 포커스 상실도 처리합니다.
- APK를 빌드할 때 `web/`을 Android 자산으로 자동 동기화합니다. 이전 웹 파일이 들어간 APK가 생성되는 것을 막습니다.

## 참고한 공식 동작

2026-10-01에 다음 안내를 확인했습니다. 제품의 내부 판정 알고리즘을 복제한 것은 아니며, 공개된 사용자 동작을 기준으로 구현했습니다.

- [Goodnotes — Scribble to Erase](https://support.goodnotes.com/hc/en-us/articles/7443501398671): 펜으로 덮은 펜 획을 지우고, 낙서 영역 밖의 별도 획은 남을 수 있습니다. 이 수정은 오인식을 줄이기 위해 반복 왕복 동작을 보수적으로 판정합니다.
- [Goodnotes — 확대·이동·스크롤](https://support.goodnotes.com/hc/en-us/articles/6554036735631): 손가락 핀치로 확대·축소하고 확대된 페이지를 이동합니다. 굿노트의 더블탭 확대도 안내되어 있지만, BADNOTE의 필기 중 배율 초기화 문제를 막기 위해 캔버스 더블클릭 맞춤은 제거했습니다.
- [Samsung Notes — S Pen 필기](https://www.samsung.com/us/support/answer/ANS10003634/): 버튼을 누르는 동안 지우개를 사용하고, 놓으면 이전 도구로 돌아갑니다. 호버 중 도구 전환과 접촉 중 지우기를 구분합니다.
- [Android MotionEvent](https://developer.android.com/reference/android/view/MotionEvent): 현재 눌린 버튼은 `getButtonState()`, 변경된 버튼은 `ACTION_BUTTON_PRESS/RELEASE`의 `getActionButton()`으로 판정합니다.

## 검증

- `tools/test_web.py`: 기존 웹 회귀 테스트. 일반적인 한 방향 지그재그·고리와 의도적인 반복 지우기 동작을 구분하도록 사례를 갱신했습니다.
- `tools/test_input_regressions.py`: 5개 표시 언어의 일반 글씨 보호, 잠긴 객체·형광펜·텍스트·도형 보호, 실행 취소·다시 실행, 지우기 방향과 배율, 버튼 누르기·떼기, 창 크기 변경과 페이지 맞춤을 검증합니다.
- 원본 `054d404`에 새 입력 테스트를 적용하면 글씨 보호, 같은 접촉 중 버튼 해제, 배율 유지 등 8개 항목에서 실패했고 수정본에서 통과했습니다.
- `StylusButtonStateTest`: MOVE만으로 전달되는 버튼 변화, 명시적 버튼 해제, 보조 버튼 유지, 펜을 들거나 취소한 경우를 검증합니다.
- 실제 S Pen 기기는 이 PC에 연결되어 있지 않아 제조사별 하드웨어 이벤트는 실기기에서 추가 확인해야 합니다.
